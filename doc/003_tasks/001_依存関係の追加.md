# DEV-001: 依存関係の追加

## 概要

libクレートに必要な依存関係を`cargo add`コマンドを使用して追加する。

## 完了条件

- [x] `riff` クレートを追加
- [x] `rmp` クレートを追加
- [x] `rmp-serde` クレートを追加
- [x] `serde` クレート（deriveフィーチャー付き）を追加
- [x] `thiserror` クレートを追加
- [x] `lib/Cargo.toml` が正しく更新されていること
- [x] `cargo build -p nksf-parser` が成功すること

## 実行コマンド

```bash
pwd  # /home/ubuntu/nksf-parser を確認
cd lib
cargo add riff
cargo add rmp
cargo add rmp-serde
cargo add serde --features derive
cargo add thiserror
cd ..
```

## 注意点

- **必ずpwdでカレントディレクトリを確認してから実行する**
- Cargo.tomlを直接編集してはいけない（`cargo add`を使用）
- 各コマンドの実行後、エラーが出ていないか確認する
- 依存関係の追加後、`cargo build`で正常にビルドできることを確認
