## 調査手順

### 1. PCHKチャンクのヘッダー解析

```bash
# Abandoned.nksfからPCHKチャンクの開始位置を特定
hexdump -C lib/tests/massive_x_factory_library_tests/fixture/Abandoned.nksf | grep -B 2 -A 20 "PCHK"
```

### 2. バイナリ構造の特定

- 最初の数バイト: ヘッダー、バージョン、フラグなど
- データセクション: パラメータ値、波形データ、設定など
- 圧縮の有無を確認
- データ型とエンディアンネスの特定

### 3. 複数ファイルでの検証

```bash
# 他のプリセットファイルとの比較
hexdump -C lib/tests/massive_x_factory_library_tests/fixture/"Alien Contact.nksf" | grep -B 2 -A 20 "PCHK"
```

### 4. パターンの抽出

- 共通のヘッダー構造
- 可変長データの識別方法
- セクション区切りの特定
