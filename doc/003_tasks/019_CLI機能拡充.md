# タスク019: CLI機能拡充

## 概要

CLIツールのコマンドラインオプションを拡充し、複数ファイルの処理、出力先の指定、上書き動作の制御を実装する。

## 目的

- ユーザビリティの向上
- バッチ処理への対応
- 柔軟な出力先指定

## タスク詳細

### 追加するオプション

#### 1. `-o, --output <FILE>` オプション
- **用途**: 出力ファイル名を指定
- **デフォルト動作**: stdoutへ出力
- **複数ファイル指定時**: このオプションは無視される

#### 2. `-d, --dir <DIRECTORY>` オプション
- **用途**: 出力ディレクトリを指定
- **デフォルト動作**: カレントディレクトリ
- **ディレクトリが存在しない場合**: エラーを出力して終了
- **`-o`との組み合わせ**: `[dir]/[output]` に出力

#### 3. `-v, --version` オプション
- **用途**: バージョン情報を表示
- **出力内容**: `nksf-parser-cli 0.1.0`

#### 4. `--overwrite` フラグ
- **用途**: 既存ファイルの上書きを許可
- **デフォルト動作**: ファイルが既に存在する場合、エラーを出力して終了
- **指定時**: 既存ファイルを上書き

### 複数ファイル入力対応

#### コマンド構文
```bash
nksf-parser-cli [OPTIONS] <INPUT> [<INPUT>...]
```

#### 動作仕様

**単一ファイル**:
```bash
# stdoutへ出力（デフォルト）
nksf-parser-cli preset.nksf

# ファイルに出力
nksf-parser-cli -o output.json preset.nksf

# ディレクトリ指定
nksf-parser-cli -d ./output preset.nksf
# → ./output/preset.json

# ディレクトリ + ファイル名指定
nksf-parser-cli -d ./output -o result.json preset.nksf
# → ./output/result.json
```

**複数ファイル**:
```bash
# カレントディレクトリに出力
nksf-parser-cli preset1.nksf preset2.nksf preset3.nksf
# → ./preset1.json, ./preset2.json, ./preset3.json

# ディレクトリ指定
nksf-parser-cli -d ./output preset1.nksf preset2.nksf
# → ./output/preset1.json, ./output/preset2.json

# -oオプションは無視される（警告を表示）
nksf-parser-cli -o ignored.json preset1.nksf preset2.nksf
# Warning: -o option is ignored when multiple input files are specified
# → ./preset1.json, ./preset2.json
```

### 出力ファイル名の生成規則

**拡張子の置き換え**:
- `preset.nksf` → `preset.json`
- `file.NKSF` → `file.json`（大文字小文字を問わない）

**パスの処理**:
- `/path/to/preset.nksf` → `preset.json`（ファイル名のみを使用）

### エラーハンドリング

#### 1. ファイル上書きエラー
```
Error: Output file 'preset.json' already exists
Hint: Use --overwrite to overwrite existing files
```

#### 2. ディレクトリ不存在エラー
```
Error: Output directory './nonexistent' does not exist
Hint: Create the directory first or check the path
```

#### 3. ディレクトリ書き込み権限エラー
```
Error: Cannot write to directory './readonly'
Hint: Check directory permissions
```

#### 4. 入力ファイル不存在エラー（既存）
```
Error: Failed to parse 'nonexistent.nksf'
Reason: [IO error details]
Hint: Check if the file exists and you have read permission.
```

```rust
use clap::Parser;
use std::path::PathBuf;

#[derive(Parser)]
#[command(
    name = "nksf-parser-cli",
    version,
    about = "Parse .nksf (Massive X preset) files and output as JSON"
)]
struct Args {
    /// Input .nksf file(s) to parse
    #[arg(required = true)]
    input: Vec<PathBuf>,

    /// Output file (default: stdout for single file, current directory for multiple files)
    #[arg(short, long)]
    output: Option<PathBuf>,

    /// Output directory (default: current directory)
    #[arg(short, long)]
    dir: Option<PathBuf>,

    /// Compact JSON output (no pretty-printing)
    #[arg(short, long)]
    compact: bool,

    /// Overwrite existing files without asking
    #[arg(long)]
    overwrite: bool,
}
```

### ステップ2: 単一ファイル処理の実装

```rust
fn process_single_file(
    input: &Path,
    output: Option<&Path>,
    dir: Option<&Path>,
    compact: bool,
    overwrite: bool,
) -> Result<(), Box<dyn Error>> {
    let nksf = nksf_parser::parse_nksf(input)?;
    let json_output = if compact {
        serde_json::to_string(&nksf)?
    } else {
        serde_json::to_string_pretty(&nksf)?
    };

    match (output, dir) {
        (None, None) => {
            // stdoutへ出力
            println!("{}", json_output);
        }
        (Some(output_file), None) => {
            // ファイルへ出力
            write_to_file(output_file, &json_output, overwrite)?;
        }
        (None, Some(dir)) => {
            // ディレクトリ指定
            let output_file = generate_output_path(input, dir);
            write_to_file(&output_file, &json_output, overwrite)?;
        }
        (Some(output_file), Some(dir)) => {
            // ディレクトリ + ファイル名
            let output_path = dir.join(output_file);
            write_to_file(&output_path, &json_output, overwrite)?;
        }
    }

    Ok(())
}
```

### ステップ3: 複数ファイル処理の実装

```rust
fn process_multiple_files(
    inputs: &[PathBuf],
    dir: Option<&Path>,
    compact: bool,
    overwrite: bool,
    output_specified: bool,
) -> Result<(), Box<dyn Error>> {
    if output_specified {
        eprintln!("Warning: -o option is ignored when multiple input files are specified");
    }

    let output_dir = dir.unwrap_or_else(|| Path::new("."));

    // ディレクトリの存在確認
    if !output_dir.exists() {
        eprintln!("Error: Output directory '{}' does not exist", output_dir.display());
        eprintln!("Hint: Create the directory first or check the path");
        process::exit(1);
    }

    for input in inputs {
        let nksf = nksf_parser::parse_nksf(input)?;
        let json_output = if compact {
            serde_json::to_string(&nksf)?
        } else {
            serde_json::to_string_pretty(&nksf)?
        };

        let output_file = generate_output_path(input, output_dir);
        write_to_file(&output_file, &json_output, overwrite)?;

        eprintln!("✓ Processed: {} -> {}", input.display(), output_file.display());
    }

    Ok(())
}
```

### ステップ4: ヘルパー関数の実装

```rust
/// 入力ファイル名から出力ファイルパスを生成
fn generate_output_path(input: &Path, output_dir: &Path) -> PathBuf {
    let file_stem = input.file_stem().unwrap();
    output_dir.join(format!("{}.json", file_stem.to_string_lossy()))
}

/// ファイルへ書き込み（上書きチェック付き）
fn write_to_file(path: &Path, content: &str, overwrite: bool) -> Result<(), Box<dyn Error>> {
    if path.exists() && !overwrite {
        eprintln!("Error: Output file '{}' already exists", path.display());
        eprintln!("Hint: Use --overwrite to overwrite existing files");
        process::exit(1);
    }

    std::fs::write(path, content)?;
    Ok(())
}
```

### ステップ5: main関数の更新

```rust
fn main() {
    let args = Args::parse();

    let result = if args.input.len() == 1 {
        process_single_file(
            &args.input[0],
            args.output.as_deref(),
            args.dir.as_deref(),
            args.compact,
            args.overwrite,
        )
    } else {
        process_multiple_files(
            &args.input,
            args.dir.as_deref(),
            args.compact,
            args.overwrite,
            args.output.is_some(),
        )
    };

    if let Err(e) = result {
        eprintln!("Error: {}", e);
        process::exit(1);
    }
}
```
