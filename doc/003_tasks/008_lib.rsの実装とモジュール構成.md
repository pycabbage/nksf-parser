## 実装ガイド

### lib.rs の構成

```rust
//! # nksf-parser
//!
//! .nksf (Massive Xのプリセットファイル) のパーサーライブラリ
//!
//! ## 使用例
//!
//! ```no_run
//! use nksf_parser::parse_nksf;
//! use std::path::Path;
//!
//! let path = Path::new("preset.nksf");
//! let result = parse_nksf(&path).unwrap();
//! println!("Preset name: {}", result.metadata.name);
//! ```

mod error;
mod types;
mod riff_reader;
mod nisi_parser;
mod nica_parser;
mod parser;

// パブリックAPI
pub use error::{ParseError, Result};
pub use types::{
    NksfFile,
    NisiMetadata,
    NiInternal,
    NicaData,
    Parameter,
    UnknownChunk,
};
pub use parser::{parse_nksf, parse_nksf_from_bytes};
```

## 注意点

- パブリックAPIのみをエクスポートする
- 内部実装の詳細（RiffReader、パーサー関数など）は非公開
- ライブラリドキュメントに使用例を記載
- モジュールの依存関係が循環していないことを確認
- 既存の `add` 関数とテストは削除する
