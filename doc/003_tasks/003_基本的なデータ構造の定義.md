# 003: 基本的なデータ構造の定義

## 概要

`lib/src/types.rs` を作成し、.nksfファイルの解析結果を格納する構造体を定義する。

## 完了条件

- [ ] `lib/src/types.rs` が作成されている
- [ ] 以下の構造体が定義されている:
  - `NksfFile`: トップレベル構造体
  - `NisiMetadata`: メタデータ（NISIチャンク）
  - `NiInternal`: `__ni_internal` フィールド
  - `NicaData`: パラメータデータ（NICAチャンク）
  - `Parameter`: パラメータ情報
  - `UnknownChunk`: 未知のチャンク（完全なバイト解析のため）
- [ ] 全ての構造体に `Serialize`, `Deserialize` が実装されている
- [ ] 適切な `#[serde(rename = "...")]` 属性が設定されている
- [ ] ドキュメントコメントが記述されている（日本語）
- [ ] ユニットテストが記述されている
- [ ] `cargo test -p nksf-parser` が成功すること
- [ ] `cargo clippy` で警告が出ないこと

## 実装ガイド

### NksfFile

```rust
/// .nksfファイルの完全な解析結果
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct NksfFile {
    /// メタデータ（NISIチャンク）
    pub metadata: NisiMetadata,
    /// パラメータデータ（NICAチャンク）
    pub parameters: NicaData,
    /// その他の未知のチャンク（完全なバイト解析のため）
    pub unknown_chunks: Vec<UnknownChunk>,
}
```

### NisiMetadata

```rust
/// NISIチャンクのメタデータ
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct NisiMetadata {
    #[serde(rename = "__ni_internal")]
    pub ni_internal: NiInternal,
    pub author: String,
    pub bankchain: Vec<String>,
    pub characters: Vec<String>,
    pub comment: String,
    #[serde(rename = "deviceType")]
    pub device_type: String,
    pub modes: Vec<String>,
    pub name: String,
    pub types: Vec<Vec<String>>,
    pub uuid: String,
    pub vendor: String,
}
```

### Parameter

```rust
/// パラメータ情報
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Parameter {
    pub autoname: bool,
    pub id: u32,
    pub name: String,
    pub vflag: bool,
}
```

### UnknownChunk

```rust
/// 未知のチャンク（完全なバイト解析のため保持）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UnknownChunk {
    /// チャンクID（4文字）
    pub id: String,
    /// チャンクのバージョン（存在する場合）
    pub version: Option<u32>,
    /// 生データ
    pub data: Vec<u8>,
}
```

## 注意点

- 全てのフィールドを適切に保持し、データを捨てない設計にする
- `unknown_chunks` フィールドで未知のチャンクも保存する
- Serde の `rename` 属性を使用してMessagePackのフィールド名と一致させる
- `NiInternal` の詳細構造は調査を進めながら拡張する（現時点では `serde_json::Value` でも可）
- ドキュメントコメントは日本語で記述（コード内コメントも日本語）
- ユニットテストはファイル内に記述する（`#[cfg(test)]` モジュール）
