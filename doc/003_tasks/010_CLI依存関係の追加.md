# 010: CLI依存関係の追加

## 概要

cliクレートに必要な依存関係を`cargo add`コマンドを使用して追加する。

## 完了条件

- [x] `serde_json` クレートを追加
- [x] `clap` クレート（deriveフィーチャー付き）を追加
- [x] `cli/Cargo.toml` が正しく更新されていること
- [x] `cargo build -p nksf-parser-cli` が成功すること

## 実行コマンド

```bash
pwd  # /home/ubuntu/nksf-parser を確認
cd cli
cargo add serde_json
cargo add clap --features derive
cd ..
```

## 注意点

- **必ずpwdでカレントディレクトリを確認してから実行する**
- Cargo.tomlを直接編集してはいけない（`cargo add`を使用）
- 各コマンドの実行後、エラーが出ていないか確認する
- 依存関係の追加後、`cargo build`で正常にビルドできることを確認
- このタスクは タスク011（CLIツールの実装）の前提条件
