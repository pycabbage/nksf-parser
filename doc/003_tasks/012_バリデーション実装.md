# 012: バリデーション実装

## 概要

フォーマット検証、バージョンチェック、必須フィールドの存在確認を各パーサーに実装する。

## 完了条件

- [ ] RIFFフォーマットの厳密な検証が実装されている
- [ ] NIKSフォーマット識別子の検証が実装されている
- [ ] チャンクバージョンのチェックが実装されている
- [ ] NISIメタデータの必須フィールド検証が実装されている
- [ ] NICAパラメータデータの必須フィールド検証が実装されている
- [ ] バリデーションエラーに対する適切なエラーメッセージがある
- [ ] ユニットテストが追加されている
- [ ] `cargo test -p nksf-parser` が成功すること

## 実装内容

### RIFFフォーマット検証（riff_reader.rs）

```rust
// RIFFヘッダーの検証を強化
- "RIFF" マジックナンバーの確認
- ファイルサイズの妥当性チェック
- "NIKS" フォーマット識別子の確認
```

### バージョンチェック（nisi_parser.rs、nica_parser.rs）

```rust
// サポートされていないバージョンの検出
if version != 1 {
    return Err(ParseError::UnsupportedVersion(version));
}
```

### 必須フィールド検証（parser.rs）

```rust
// NisiMetadata の必須フィールド
- name が空でないこと
- vendor が空でないこと
- device_type が空でないこと

// NicaData の必須フィールド
- ni8 配列が空でないこと
- パラメータIDが重複していないこと
```

## エラー型の追加

`error.rs` に新しいエラーバリアントを追加:

```rust
#[derive(Error, Debug)]
pub enum ParseError {
    // ... 既存のエラー ...

    #[error("Unsupported version: {0}")]
    UnsupportedVersion(u32),

    #[error("Missing required field: {0}")]
    MissingRequiredField(String),

    #[error("Invalid field value: {0}")]
    InvalidFieldValue(String),
}
```

## 注意点

- バリデーションは早い段階で失敗させる（fail-fast）
- エラーメッセージは具体的で分かりやすくする
- 既存のテストが引き続きパスすることを確認
- バリデーションエラーに対するテストケースを追加
