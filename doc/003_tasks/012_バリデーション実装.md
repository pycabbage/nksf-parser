## 実装内容（未実装部分のみ）

### NISIメタデータのフィールド検証

parser.rs に検証関数を追加:

```rust
/// NISIメタデータの必須フィールドを検証
fn validate_nisi_metadata(metadata: &NisiMetadata) -> Result<()> {
    if metadata.name.is_empty() {
        return Err(ParseError::InvalidNiks);
    }
    if metadata.vendor.is_empty() {
        return Err(ParseError::InvalidNiks);
    }
    if metadata.device_type.is_empty() {
        return Err(ParseError::InvalidNiks);
    }
    Ok(())
}
```

parse_nksf_from_reader内で呼び出し:
```rust
let metadata = metadata.ok_or(ParseError::InvalidNiks)?;
validate_nisi_metadata(&metadata)?; // 追加
```

### NICAパラメータIDの重複チェック

parser.rs に検証関数を追加:

```rust
/// NICAパラメータのID重複を検証
fn validate_nica_parameters(parameters: &NicaData) -> Result<()> {
    use std::collections::HashSet;

    for array in &parameters.ni8 {
        if let Some(params) = array.as_array() {
            let mut ids = HashSet::new();
            for param in params {
                if let Some(id) = param.get("id").and_then(|v| v.as_u64()) {
                    if !ids.insert(id) {
                        return Err(ParseError::InvalidNiks);
                    }
                }
            }
        }
    }
    Ok(())
}
```

## エラー型の追加（オプション）

より具体的なエラー情報が必要な場合、`error.rs` に新しいエラーバリアントを追加できます:

```rust
#[derive(Error, Debug)]
pub enum ParseError {
    // ... 既存のエラー ...

    #[error("Empty required field: {0}")]
    EmptyRequiredField(String),

    #[error("Duplicate parameter ID: {0}")]
    DuplicateParameterId(u64),
}
```

**注**: 現時点では `InvalidNiks` エラーで十分機能しているため、この追加はオプションです。
