# DEV-002: エラー型の定義

## 概要

`lib/src/error.rs` を作成し、パーサーで使用するエラー型を定義する。

## 完了条件

- [ ] `lib/src/error.rs` が作成されている
- [ ] `ParseError` 列挙型が定義されている
- [ ] 以下のエラーバリアントが含まれている:
  - `InvalidRiff`: 不正なRIFFフォーマット
  - `InvalidNiks`: 不正なNIKSフォーマット
  - `MessagePackError`: MessagePackデシリアライズエラー
  - `IoError`: I/Oエラー
  - `UnknownChunk`: 未知のチャンク
  - `IncompleteParse`: 未解析のバイトが残っている（完全なバイト解析要件）
- [ ] `thiserror::Error` トレイトを使用している
- [ ] 適切な`#[from]`属性が設定されている
- [ ] ユニットテストが記述されている
- [ ] `cargo test -p nksf-parser` が成功すること
- [ ] `cargo clippy` で警告が出ないこと

## 実装例

```rust
use thiserror::Error;

#[derive(Error, Debug)]
pub enum ParseError {
    #[error("Invalid RIFF format")]
    InvalidRiff,

    #[error("Invalid NIKS format")]
    InvalidNiks,

    #[error("MessagePack deserialization error: {0}")]
    MessagePackError(#[from] rmp_serde::decode::Error),

    #[error("IO error: {0}")]
    IoError(#[from] std::io::Error),

    #[error("Unknown chunk: {0}")]
    UnknownChunk(String),

    #[error("Incomplete parse: {0} bytes remaining at offset {1}")]
    IncompleteParse(usize, usize),
}

pub type Result<T> = std::result::Result<T, ParseError>;

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_error_display() {
        let err = ParseError::InvalidRiff;
        assert_eq!(err.to_string(), "Invalid RIFF format");
    }
}
```

## 注意点

- エラーメッセージは英語で記述する
- `IncompleteParse` エラーは、全バイト解析要件を満たすために重要
- エラー型は将来的に拡張可能な設計にする
- ユニットテストはファイル内に記述する（`#[cfg(test)]` モジュール）
