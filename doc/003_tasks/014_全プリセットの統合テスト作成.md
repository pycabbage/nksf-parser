# 014: 全プリセットの統合テスト作成

## 概要

`lib/tests/massive_x_factory_library_tests/fixture/` ディレクトリ内の全.nksfファイルに対する統合テストを作成する。

## 完了条件

- [x] 代表的なプリセットファイルに対するテストファイルが作成されている
  - abandoned_test.rs（詳細テスト）
  - alien_contact_test.rs
  - all_rise_test.rs
- [x] 各テストファイルが `mod.rs` に登録されている
- [x] 各テストで以下を確認している:
  - ファイルが正常に解析できること
  - 基本的なメタデータ（name, author, vendor）が存在すること
  - パラメータデータが存在すること
  - 完全なバイト解析が行われていること
- [x] `cargo test -p nksf-parser` で全テストがパスすること
- [x] テスト実行時間が妥当であること（全体で数秒以内）

**注**: 全100個のプリセットファイルに対する個別テストファイル作成は非現実的なため、
代表的な3個の詳細テストを作成。残りの全プリセットはタスク015のループテストでカバーする。

## 実装手順

### 1. プリセットファイルの一覧取得

```bash
ls lib/tests/massive_x_factory_library_tests/fixture/*.nksf | wc -l
```

### 2. テストファイルの生成

各プリセットに対して `<preset_name>_test.rs` を作成（スペースをアンダースコアに置換）:

```rust
// 例: alien_contact_test.rs
use nksf_parser::parse_nksf;
use std::path::PathBuf;

fn get_fixture_path() -> PathBuf {
    PathBuf::from(env!("CARGO_MANIFEST_DIR"))
        .join("tests")
        .join("massive_x_factory_library_tests")
        .join("fixture")
        .join("Alien Contact.nksf")
}

#[test]
fn test_alien_contact_parse_success() {
    let path = get_fixture_path();
    let result = parse_nksf(&path);
    assert!(result.is_ok(), "Failed to parse: {:?}", result.err());
}

#[test]
fn test_alien_contact_metadata() {
    let path = get_fixture_path();
    let nksf = parse_nksf(&path).expect("Failed to parse");

    assert_eq!(nksf.metadata.name, "Alien Contact");
    assert!(!nksf.metadata.author.is_empty());
    assert_eq!(nksf.metadata.vendor, "Native Instruments");
}

#[test]
fn test_alien_contact_parameters() {
    let path = get_fixture_path();
    let nksf = parse_nksf(&path).expect("Failed to parse");
    assert!(!nksf.parameters.ni8.is_empty());
}
```

### 3. mod.rs の更新

各テストファイルを `mod.rs` に追加:

```rust
mod abandoned_test;
mod alien_contact_test;
mod all_rise_test;
// ... 全プリセット分追加
```

## 自動化スクリプト（オプション）

テストファイル生成を自動化するスクリプトを作成可能:

```bash
#!/bin/bash
cd lib/tests/massive_x_factory_library_tests/fixture

for file in *.nksf; do
    # ファイル名からテスト名を生成
    name=$(basename "$file" .nksf)
    test_name=$(echo "$name" | tr ' ' '_' | tr '[:upper:]' '[:lower:]')

    # テストファイルを生成
    # ...
done
```

## 注意点

- ファイル名にスペースが含まれる場合は適切にエスケープ
- テスト名はRustの命名規則に従う（スネークケース）
- 大量のテストファイルになるため、共通ヘルパー関数を検討
- CI/CDでの実行時間を考慮
