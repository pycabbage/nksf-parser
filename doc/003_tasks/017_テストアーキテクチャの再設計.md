# 017: テストアーキテクチャの再設計

## 概要

テスト用固定値とテスト実行コードを完全に分離し、全720プリセットに対する詳細テストを実現する。

## 完了条件

### 1. テストロジックの汎用化

- [ ] `lib/tests/massive_x_factory_library_tests/abandoned_test.rs` を `lib/tests/fixture_test.rs` にリネーム
- [ ] `fixture_test.rs` を汎用化し、任意のプリセットの期待値を受け取れるように修正
- [ ] テスト関数がExpectedData構造体を引数として受け取る設計に変更
- [ ] ファイルパスも引数化し、どのプリセットでもテストできるようにする

### 2. 期待値ファイルの生成

- [ ] 全720個のプリセットファイルに対する期待値ファイルを生成
  - `<preset_name>_expected_data.rs` × 720個
  - 各ファイルにphf_mapを使用した静的期待値データを含む
- [ ] 期待値生成スクリプトを作成（自動化）
- [ ] 各期待値ファイルが `mod.rs` に登録されている
- [ ] 期待値ファイルのフォーマットが統一されている

### 3. integration.rsの修正

- [ ] `test_parse_all_fixture_files` 関数を削除
- [ ] ループテストの代わりに、個別の詳細テストで全720プリセットをカバー

### 4. テスト実行の確認

- [ ] `cargo test -p nksf-parser` で全テストが成功すること
- [ ] 全720プリセットの詳細テストが実行されること
- [ ] テスト実行時間が許容範囲内であること（10分以内を目安）

```rust
#[test]
fn generate_all_preset_expected_data() {
    let fixture_dir = PathBuf::from(env!("CARGO_MANIFEST_DIR"))
        .join("tests")
        .join("massive_x_factory_library_tests")
        .join("fixture");

    for entry in std::fs::read_dir(&fixture_dir).unwrap() {
        let entry = entry.unwrap();
        let path = entry.path();

        if path.extension().and_then(|s| s.to_str()) == Some("nksf") {
            let file_name = path.file_stem().unwrap().to_str().unwrap();

            // プリセットを解析
            let nksf = parse_nksf(&path).expect("Failed to parse");

            // 期待値ファイルを生成
            let expected_code = generate_expected_data_code(&nksf, file_name);

            // ファイルに保存
            let safe_name = file_name.to_lowercase().replace(" ", "_");
            let output_path = fixture_dir.parent().unwrap()
                .join(format!("{}_expected_data.rs", safe_name));

            std::fs::write(&output_path, expected_code).unwrap();

            println!("Generated: {}_expected_data.rs", safe_name);
        }
    }
}
```
